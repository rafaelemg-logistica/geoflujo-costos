# Contribuir a GeoFlujo Costos

1. Crea una rama desde `main`.
2. Mantén los cálculos independientes de la interfaz y añade pruebas a cualquier cambio del motor.
3. Ejecuta `pnpm check` antes de abrir un pull request.
4. No incluyas geodatabases, proyectos ArcGIS, archivos Excel del piloto, credenciales ni información personal.

Los reportes de errores deben incluir los pasos para reproducir, el navegador y si la ruta se obtuvo con OSRM o con la contingencia.
